# My Little Store

**A modern online store built with React, Vite, and TailwindCSS**

---

## Overview

My Little Store is a responsive e-commerce web application where users can browse products, add them to a shopping cart, and simulate checkout. The project showcases front-end skills with React, state management, and clean UI design.

## Features

* Browse a variety of products with images and details
* Add/remove products to/from the shopping cart
* Product filtering and sorting
* Responsive design for desktop and mobile
* Modern UI with TailwindCSS
* Ready for deployment

## Technologies

* React
* Vite
* TailwindCSS
* JavaScript (ES6+)
* GitHub Actions (CI build)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/sarayousefii/my_little_store.git
```

2. Navigate to the project folder:

```bash
cd my_little_store
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Build for production:

```bash
npm run build
```

## Deployment

The project can be easily deployed to services like Vercel, Netlify, or any static hosting. The GitHub Actions CI workflow ensures the project builds correctly on every push to `main`.
